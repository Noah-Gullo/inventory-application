# Inventory Application
## Link:
https://inventory-application-production-3d79.up.railway.app/

## Description:
An inventory management app that manages books, authors, and different genre's. You can view book details including title, author name, release date, and genre. You can click on a genre to view all books listed in that genre. You can perform all CRUD operations including creating new books/genres, viewing all genres, books within genres, and specific book details. You can edit/update the genre names and various book details and you can delete genres and books.

## Reflection:
A simple project that managed and implemented a PostegreSQl database along with the associated CRUD operations while further reinforcing concepts such as routing, views, controllers, and the Model-View-Controller (MVC) architecture in a simple full-stack web application. Good practicing developing a full stack application with a database and server side code along with figuring out deployment on a Platform as a Service (PaaS) site through [railway.com](https://railway.com/).
